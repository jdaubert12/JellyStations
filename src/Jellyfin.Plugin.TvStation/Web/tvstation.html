Family hours (optional)
Keep stronger ratings out of the daytime, for example nothing above PG between 06:00 and 20:00 (station time zone). Anything that would overlap the window moves to a later slot; if nothing may play, a station card shows instead. Time blocks are not affected.

Optional short identifier, e.g. WKRP.
With a grid, a “Station Break” slate pads each program so the next one starts on the grid (e.g. :00 / :30), like a real channel. “By length” gives a 22-minute episode a half-hour slot and a 95-minute film a two-hour slot. Without padding, programs start as soon as the previous ends.

Settings

Plugin-wide defaults for every station. Encoding can be overridden per station; everything else applies everywhere.

tuneDefault encoding

Every program on every station is normalized to this profile so the stream never changes format mid-air. Stations can override it individually.

bookmarkBlock templates

Time blocks saved from a station editor with the bookmark button. Pick one from the dropdown next to “Add block” to reuse it on any station.
